# Introducción a la Computación Heterogénea

Repositorio de laboratorios y prácticas del curso de Introducción a la Computación Heterogénea.

## Especificaciones del equipo

| Componente | Especificación |
|---|---|
| Fabricante | Lenovo |
| Modelo | Lenovo V15-IIL (82C5) |
| Arquitectura | x86-64 |
| Procesador | Intel Core i5-1035G1 |
| Núcleos e hilos | 4 núcleos, 8 hilos |
| Frecuencia | 1.00 GHz base, hasta 3.60 GHz |
| Caché L1 | 192 KiB de datos + 128 KiB de instrucciones |
| Caché L2 | 2 MiB |
| Caché L3 | 6 MiB |
| Extensiones vectoriales | AVX, AVX2 y AVX-512 |
| Memoria RAM reconocida por el sistema | 7.1 GiB |
| Almacenamiento interno | Samsung MZALQ256HAJD-000L2 NVMe, 238.5 GiB |
| Gráficos | Intel Iris Plus Graphics G1 |
| Red inalámbrica | Realtek RTL8822CE 802.11ac |
| Sistema operativo | Ubuntu 26.04.1 LTS |
| Kernel | Linux 7.0.0-30-generic |
| Compilador | GCC 15.2.0 |
| BIOS | Lenovo DKCN53WW, 31 de mayo de 2021 |

Las capacidades y dispositivos fueron consultados directamente desde Linux mediante `lscpu`, `free`, `lsblk`, `lspci`, `uname` y la información DMI del sistema.
